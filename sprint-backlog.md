
# PowerShare – Sprint Backlog

## 1. Sprint Overview

**Project:** PowerShare  
**Sprint:** Sprint 1  
**Sprint Duration:** [23 sep 2026- 27 sep 2026]

### Sprint Goal

To plan and develop the core PowerShare rental process, helping micro-entrepreneurs find available portable power stations, understand rental prices and request rentals during power outages.

## 2. Selected User Stories

### User Story 1: View Available Power Stations

As a small-business owner, I want to view available portable power stations so that I can find backup power for my business.

**Tasks:**
- Identify the information users need about each power station.
- Design the power station listings page.
- Review the design against user needs.
- Test the page when implemented.

### User Story 2: View Rental Prices

As a micro-entrepreneur, I want to view rental prices before booking so that I can choose an affordable option.

**Tasks:**
- Identify the rental pricing information to display.
- Design the pricing section.
- Check that prices are easy to understand.
- Test the pricing display when implemented.

### User Story 3: Rent a Power Station

As a small-business owner, I want to request a power station rental so that I can continue essential business activities during power outages.

**Tasks:**
- Identify the information required for a rental request.
- Design the rental request form.
- Plan input validation and confirmation messages.
- Test the request process when implemented.
